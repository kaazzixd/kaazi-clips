# Kaazi Clips

**Free open-source AI video clipper for Windows**  
By **kaazixd**.

Turn YouTube, Twitch and Kick streams into ready-to-post Shorts, Reels and TikToks — entirely on your own PC.

- Local AI (Ollama + Whisper + YOLOv8) by default
- No subscription, no per-clip fees
- Your footage never leaves your machine
- Speaker-aware face tracking, word-synced captions, AI titles & hashtags

## Quick start (Windows)

```powershell
git clone https://github.com/kaazzixd/kaazi-clips.git
cd kaazi-clips
```

See **SETUP.md** and the `docs/` folder for development and build instructions.

The project produces a complete Windows installer that bundles Python, FFmpeg, models and the Electron app.
