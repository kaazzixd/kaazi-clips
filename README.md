# Kaazi Clips

**Free open-source AI video clipper for Windows**  
Local Opus Clip / Klap / Vizard alternative by **kaazixd**.

Turn YouTube, Twitch and Kick streams into ready-to-post Shorts, Reels and TikToks — entirely on your own PC.

- Local AI (Ollama + Whisper + YOLOv8) by default
- No subscription, no per-clip fees, your footage never leaves your machine
- Speaker-aware face tracking, word-synced captions, AI titles & hashtags
- Based on the excellent [Clips Kitty](https://github.com/ColinGPT9/clips-studio) project (AGPL-3.0)

## Quick start (Windows)

```powershell
git clone https://github.com/kaazzixd/kaazi-clips.git
cd kaazi-clips
```

See **SETUP.md** and the `docs/` folder for full development and build instructions.

The original project is designed to produce a complete Windows installer that bundles Python, FFmpeg, models and the Electron app.
